# The repackaging — what ships changed, what we found did not

The reviewer's course correction: the useful artifact is the METHOD (the
blocklist routing lane plus the corrected evaluation), not our model.
`strikeone` is now an installable bring-your-own-scorer package with a CLI
and an Ink terminal UI. Nothing measured changed: every stage report,
correction banner, pre-registration, and invariant stands, and the frozen
IEEE-CIS run is the worked example that proves the method.

## What shipped (full scope, items 1-5 of the mandate)

- **`strikeone check`** — input contract (transaction_id, timestamp,
  amount, entity[, label + delay][, score][, p]) with column mapping
  (`--map k=v`, persisted to `.strikeone.toml`), readers for
  parquet/CSV/DB URL, and refusals that are loud and fixable: non-binary
  labels, unparseable or constant timestamps, delays longer than the data
  window, duplicated ids. A pandas-3 unit regression (datetime64[us]
  silently shrinking 40 days to 0.04) was caught by a test during the
  build and is now pinned by one.
- **`strikeone audit`** — the core. On anyone's labelled data: episode
  structure, blocklist-alone recovery under the stated label delay, and
  (with a score) headline AP/AUC vs first-strike recall, redundancy rate,
  friction efficiency, and wrongly-flagged counts per review budget, with
  the gap stated in one plain sentence. `--json` everywhere.
- **`strikeone route`** — two-lane routing around any scorer
  (retrospective from labels, or prospective from a `--blocklist` file),
  with the measured first-strike lift across the capacity curve and the
  lane's own legitimate blocks counted.
- **`strikeone policy`** — declared-range economics in,
  approve/step-up/block out, sensitivity grid and the honest worst corner
  shown; refuses uncalibrated input rather than calibrating on the
  caller's evaluation data.
- **`strikeone tui`** — Ink app (TypeScript) as the PARENT process
  spawning `python -m strikeone.rpc` (newline-delimited JSON over stdio;
  no HTTP, no ports, offline). Six keyboard-driven tabs: CONNECT, AUDIT,
  ROUTE, ECONOMICS, STREAM, CASE. Braille capacity charts, block-digit
  counters, colour only on data, NO_COLOR respected, `--frame <tab>` for
  deterministic headless captures. The Python CLI needs no Node.
- **Examples**: the IEEE-CIS mapping, a PSP-shaped disputes mapping with
  a synthetic sample (the shape a PSP disputes API returns), and
  `--example synthetic` so a clean clone sees something real in one
  command without vendoring any dataset rows.

## Two semantics stated rather than hidden

1. **The generic audit treats a file as a standalone window** — exactly
   as it must treat a customer's export, where history outside the file
   does not exist. `--example ieee-cis` therefore reports within-window
   episode counts (1,462) that legitimately differ from the frozen stage
   reports (1,198, computed with the full 182-day stream behind the same
   window). The CLI prints this caveat with the numbers.
2. **The instant demo is synthetic and says so** on every run. The
   IEEE-CIS worked example binds to locally built pipeline outputs; if
   absent, the tool prints the exact rebuild chain instead of vendoring
   data.

## Invariants, re-verified at this gate

Holdout access log: exactly one entry. Frozen model/calibration/config
untouched (the worked example reads the same frozen artifacts). Nothing
hardcoded (every figure computed live from the loaded data; the gate
captures were generated by running the real TUI headlessly against the
real backend). False positives and lane-1 legitimate blocks visible at
equal weight in the TUI (AUDIT's wrongly-flagged stat and column, ROUTE's
counted legit blocks). Cost parameters clamped to the declared ranges
with the honest corner shown. Ground-truth roles labelled as an
evaluation overlay on the CASE tab and in every relevant output.
Chronological ordering enforced once, in the contract layer; `check`
refuses what would violate point-in-time correctness.

The web console remains as an optional extra (`strikeone console`),
demoted: the README and the video lead with the package and the TUI.
