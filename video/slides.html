On the most widely used public benchmark for card fraud, the standard evaluation cannot distinguish preventing fraud from remembering it — and it systematically prefers the model that remembers.

Strike One — measured on IEEE-CIS under a chronological protocol, confirmed on a sealed holdout opened once.

How the labels were made — the host's own rule

"…define reported chargeback on the card as fraud transaction (isFraud=1) and transactions posterior to it with either user account, email address or billing address directly linked to these attributes as fraud too. If none of the above is reported and found beyond 120 days, then we define it as legit transaction (isFraud=0)."

One positive class, two different things: the transaction where an episode starts — and everything after, which any blocklist already covers.
